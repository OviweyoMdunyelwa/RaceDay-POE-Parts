# RaceDay – Part 2

This folder contains the RaceDay ASP.NET Core Web API and its unit tests.

## Projects
- `RaceDay.API` – the main Web API project.
- `RaceDay.API.Tests` – the unit testing project.

The API uses C#, ASP.NET Core, Entity Framework Core and SQL Server. It includes authentication, role-based access control and event management functionality.
